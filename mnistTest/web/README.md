# 手写数字识别网页

网页打开后自动在后台加载模型，并显示加载状态；模型就绪后可点击识别。加载失败时可点击“重新加载”。网页在浏览器内完成预测，不需要 Python 后端。支持全连接网络与 CNN，以及跟随系统、浅色、深色三种外观。画布被转换为 28×28 灰度图后再输入模型；网页显示模型实际看到的图像。

本地预览（在 `mnistTest` 目录运行）：

```bash
python3 -m http.server 8000 --directory web
```

然后访问 http://127.0.0.1:8000/。手机与电脑在同一局域网时，可访问 `http://电脑局域网IP:8000/`。本地服务开放给同一网络可访问该端口的设备；结束时按 Ctrl+C。

每次重新训练后，使用下面的命令将两个最新模型导出到 `web/models`，然后重新发布网页：

```bash
python3 tools/export_models.py
```

可通过 `--mlp` 和 `--cnn` 指定模型路径，通过 `--output` 指定导出目录。网页的下拉列表使用上一次导出并发布的模型，并不自动读取电脑上的训练目录。模型文件以及推理代码在浏览器中公开可见。模型预测分数不保证经过概率校准，网页手写风格不同于 MNIST，可能识别错误。
