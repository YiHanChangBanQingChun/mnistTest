# 使用 NumPy 从零实现卷积神经网络

这个版本在原有全连接网络旁边，增加一个用于 MNIST 的卷积神经网络（CNN）。卷积、最大池化、ReLU、Softmax、交叉熵、反向传播和带动量的梯度下降均由 NumPy 实现；不依赖 PyTorch、TensorFlow 或其他机器学习框架。NumPy 负责数组和矩阵运算，PyYAML 负责配置读取，MNIST 解压与 CSV 输出复用项目原有代码。

## 1. 如何运行

在 `mnistTest` 目录运行：

```bash
python3 -m pip install -r requirements.txt
python3 src-cnn/main.py
```

训练完成后，可以加载指定模型，对配置中的 MNIST 测试集重新预测：

```bash
python3 src-cnn/main.py --model runs-cnn/某次训练目录/model.npz
```

配置位于 `src-cnn/config.yaml`。也可以使用 `--config /path/to/config.yaml` 指定其他配置；**数据与输出的相对路径均以配置文件所在目录为基准**。原始数据和原先全连接网络的配置不会被修改。

`channels` 设置两个卷积层的通道数，`hidden_size` 设置全连接隐藏层大小；`epochs`、`batch_size`、`learning_rate`、`momentum` 和 `validation_size` 控制训练。默认使用随机种子 42，把原始训练集划分为 50,000 个训练样本和 10,000 个验证样本；测试集仅在训练结束后评估。

手写 NumPy 卷积使用 CPU，运行时间随硬件、BLAS 实现和超参数变化，通常比调用专门优化的深度学习框架慢。不同运行环境下设置合适的 BLAS 线程数可能改善性能，例如 macOS 可在命令前加 `OPENBLAS_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1`，实际以本机测试为准。

## 2. 训练与预测的输出

默认每次运行在 `runs-cnn/日期_时间_随机后缀/` 下创建独立目录。与原全连接版本使用相同的文件名及 CSV 列：

| 文件 | 内容 |
| --- | --- |
| `run.log` | 参数、每轮指标、最终测试结果与错误信息 |
| `config.yaml` | 运行配置快照，相对路径仍以**原配置文件**目录为基准 |
| `training.csv` | 每轮训练损失、验证损失、验证准确率、耗时；仅训练模式生成 |
| `predictions.csv` | 测试集逐样本索引、真实标签、预测标签、是否正确和 10 个类别概率 |
| `model.npz` | 网络结构和权重，仅训练模式生成 |

`train_loss_during_updates` 是各 batch **更新前**的损失按样本数加权的平均值；由于不同 batch 之间会更新参数，它不等于用同一组 epoch 结束参数重新计算的训练集损失。验证指标使用该轮结束后的参数计算。`--model` 仅用于预测，不支持恢复优化器动量或继续训练。

CNN 的 `model.npz` 与原全连接模型的内部格式不同。脚本的预测入口面向 MNIST 测试集；网页使用 `tools/export_models.py` 导出的静态权重，在浏览器中执行推理。网页使用方式见 `web/README.md`。

## 3. 与原全连接网络的区别

原模型把 28×28 图片直接展平为 784 个数，再送入全连接层。CNN 首先保留图片的行、列结构，用较小的卷积核扫描图像。一个卷积核在不同位置共用同一组权重，因此可以学习在不同位置出现的局部笔画。多个卷积核各自得到不同的特征图，再由后续层组合特征。

本例默认数据流如下，`N` 为一个 batch 的样本数，图像张量使用 **NCHW** 顺序：样本数、通道数、高、宽。

```text
输入图片       (N,  1, 28, 28)     像素除以 255
   │
   ├─ 3×3 卷积，8 个卷积核，步长 1，补零 1 → ReLU
   ├─ 2×2 最大池化，步长 2                    (N,  8, 14, 14)
   ├─ 3×3 卷积，16 个卷积核，步长 1，补零 1 → ReLU
   ├─ 2×2 最大池化，步长 2                    (N, 16,  7,  7)
   ├─ 展平 → 全连接 64 → ReLU
   └─ 全连接 10 → logits → Softmax → 十类概率
```

层数与通道数由配置控制，但本实现固定使用两个卷积层和两个池化层。卷积保留局部空间信息，池化缩小特征图；它们可能有助于识别不同位置的笔画，但并不保证对任意书写形态或网页预处理都准确。

## 4. 前向传播

### 卷积与 ReLU

输入 $X$ 经过补零后，卷积层第 $o$ 个输出通道的第 $(i,j)$ 个位置为：

$$
Z_{n,o,i,j}=b_o+\sum_{c}\sum_{u=0}^{2}\sum_{v=0}^{2}
W_{o,c,u,v}\,X^{\mathrm{pad}}_{n,c,i+u,j+v}.
$$

这里按机器学习中的常用习惯称为卷积，严格来说该计算没有翻转卷积核，是**互相关**。代码通过 `sliding_window_view` 提取窗口并整理为列矩阵，再使用矩阵乘法一次计算多个位置。权重采用 He 正态初始化，偏置初始为 0。

每个位置再经过 ReLU：

$$
A=\operatorname{ReLU}(Z)=\max(0,Z), \qquad
\frac{\partial A}{\partial Z}=\begin{cases}1,&Z>0\\0,&Z\le 0.\end{cases}
$$

本实现按上述约定在 $Z=0$ 处取导数 0。

### 最大池化

每个不重叠的 2×2 窗口取最大值，例如：

$$
\begin{bmatrix}1&3\\2&0\end{bmatrix}\longrightarrow 3.
$$

池化没有需要学习的权重。前向传播记录最大值位置，供反向传播使用；如果最大值并列，本实现选择第一个位置。

### 分类与损失

第二次池化后展平，经全连接隐藏层和输出层得到 10 个 logits $v$。对第 $k$ 类，Softmax 为：

$$
p_k=\frac{e^{v_k-\max_j v_j}}{\sum_j e^{v_j-\max_j v_j}}.
$$

对 batch 中第 $i$ 个样本的真实标签 $y_i$，平均交叉熵为：

$$
J=-\frac{1}{B}\sum_{i=1}^{B}\log p^{(i)}_{y_i}.
$$

代码使用 `log-sum-exp` 形式避免先取接近零的概率再取对数。

## 5. 反向传播与更新

Softmax 加交叉熵的组合给出输出层梯度：

$$
\Delta_{\mathrm{out}}=\frac{P-Y}{B},
$$

其中 $Y$ 表示概念上的独热标签，代码直接在真实类别位置减 1，不必构造完整独热矩阵。全连接层 $Z=AW+b$ 的梯度为：

$$
\nabla_WJ=A^T\Delta,\quad \nabla_bJ=\sum_n\Delta_n,\quad
\nabla_AJ=\Delta W^T.
$$

经过 ReLU 时，把上游梯度乘以正输入位置的掩码；经过最大池化时，仅把梯度送回前向选中的最大值位置。对于卷积层，权重梯度在**所有样本和空间位置**上累加；输入中同一个像素可能参与多个卷积窗口，因此输入梯度也要把来自重叠窗口的贡献相加。`Conv2D.backward` 中的循环正是完成这一步。

所有层梯度计算完后，再用带动量的小批量梯度下降更新。对任意参数 $\theta$：

$$
v_t=\mu v_{t-1}+\nabla_\theta J_t,\qquad
\theta\leftarrow\theta-\eta v_t.
$$

$\eta$ 是学习率，$\mu$ 是动量系数，初始 $v_0=0$。动量会累积历史梯度方向，因此它和只使用当前梯度的普通 SGD 不完全相同。

## 6. 阅读代码的顺序

1. `main.py`：数据读取、训练循环、评估和结果文件。
2. `cnn.py` 中的 `CNN.forward`：完整前向数据流。
3. `Conv2D`、`MaxPool2D`、`Dense`：各层的前向和反向公式。
4. `CNN.backward` 与 `train_batch`：梯度从输出向输入传播，最后更新参数。

训练集准确率和 MNIST 测试集准确率不能代替网页鼠标手写数据的实际准确率；如需比较网页识别能力，应另外收集有标签的网页手写样本，并使用相同样本比较两个模型。
